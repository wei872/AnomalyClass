# FabricNCD 设计文档

> 目标：在**单模型、轻量化（≈1.1 M 参数 / 0.62 GMACs @512）**约束下，同时做好
> 布匹疵点的**检测（定位）**、**多类分类**与**新类发现**，并在"布种多、布幅变、布边/布中不一致"的
> 条件下保持**强泛化**。

---

## 1. 问题拆解

布匹视觉任务的难点与对应设计：

| # | 难点 | 具体表现 | 对应设计 |
|---|---|---|---|
| 1 | 缺陷极弱、极小 | 断经 = 一根纱线中断，宽 1–3 px；油点线对比度低 | 1/8 稠密异常图（不靠框回归）；Gabor 相位响应；Focal(α=0.65)+Dice |
| 2 | 纹理是准周期结构 | 经纬交织，正常纹理本身高频、强边缘 | Gabor 先验 + 织造周期归一化 + 高频归一化（去光照/低频） |
| 3 | 布边 ≠ 布中 | 边组织、包边、纬密不同，边缘本身"反常" | 布面/布边掩码头 + "到布边软距离" embedding + 布边带加权损失 |
| 4 | 布幅会变 | 走偏/换幅宽 → 布边位置移动，背景占比变化 | 布幅增广（背景画布/布边延伸）+ 距离而非坐标编码 + 布面掩码后处理 |
| 5 | 布种繁多 | 平纹/斜纹/提花/密度差异大 | 织造尺度归一化 + 与外观无关的纹理/相位特征 + 正常图记忆库 |
| 6 | 新疵点不断出现 | 闭集分类器失效 | 原型度量分类 + 无监督聚类新类发现 + 记忆库开放集打分 |
| 7 | 标注昂贵且不均衡 | 稀有类样本少 | 弱监督（框内像素）、合成异常自监督、SupCon 度量学习 |
| 8 | 产线要求轻量实时 | 边缘设备、CPU 部署 | MobileNetV3-Small + 1x1/depthwise 头 + 1/8 计算 + ONNX/TensorRT |

## 2. 总体架构

```
                        ┌──────────────── 织造周期估计 (FFT) ───────────────┐
                        │  period_x, period_y, anisotropy, confidence      │
                        ▼                                                 │
x (B,3,H,W) ──► Backbone (MobileNetV3-Small, 抽头 p2/p3/p4/p5)             │
   │                    │        │        │        │                      │
   │                 p2 1/4    p3 1/8   p4 1/16  p5 1/32                  │
   │                    │        │        │        │                      │
   ├──► TextureEncoder ─┘        │        │        └──► GlobalContext ◄───┘
   │    (Gabor 16 + 1x1)         │        │            (dilated + linear attn
   │         │                   │        │             + weave token)
   │         └────► concat ──────┘        │                  │
   │                    │                 │                  │
   │                    └──► GlocalFusion ◄─────────────────┘
   │                          (lat p3/p4/global + FiLM(global))
   │                              │
   │                 ┌────────────┴─────────────┐
   │                 │  mask_stem (1/4)         │
   │                 │  FabricMaskHead          │
   │                 │  → cloth_prob, boundary   │
   │                 └────────────┬─────────────┘
   │                              ▼
   │                    GeographyEmbedding(1/8)  (多尺度池化金字塔 ≈ 到布边距离)
   │                              │
   │             ┌────────────────┼──────────────────┐
   │        AnomalyHead      EmbeddingHead      PrototypeClassifier
   │          (1/8,1ch)        (1/8,64d)            (19 类, 余弦)
   │             │                │                    │
   │             │         MemoryBank (2048×64) ◄──────┘
   ▼             ▼
 异常图 = (1-w)·σ(anomaly) + w·clip(1-sim)/τ        → 区域分析 → 区域合并 → 图像级类别
```

### 2.1 主干与抽头

- 默认 `torchvision.models.mobilenet_v3_small`（ImageNet 预训练），通过一次探测自动选择
  `p2/p3/p4/p5` 四个 stride 的**最深的、通道数 ≤ 320 的**层，跳过末尾 576 维 1×1 投影
  （对分割/度量收益小、计算量大）。
- 无 torchvision 或需端侧一致性时，可切换 `arch: lite`（纯 PyTorch 实现的同拓扑主干）。
- 浅层可冻结（`freeze_stages`），小数据下减少过拟合，同时保留浅层通用纹理/边缘特征。

实测（512×512，batch=1，CPU 2 核）：

| 配置 | 参数量 | MACs | 延迟 |
|---|---|---|---|
| 全模型 | 1.11 M | 0.62 G | ≈ 100 ms |
| 主干 | 0.93 M | ≈ 0.20 G | ≈ 35 ms |

## 3. 纹理先验

### 3.1 Gabor 滤波器组

二维 Gabor：

```
G(x,y) = exp(-(x'² + γ²y'²) / (2σ²)) · cos(2πx'/λ + ψ)
x' = x cosθ + y sinθ,  y' = -x sinθ + y cosθ
```

- 方向 θ ∈ {0°, 45°, 90°, 135°}：0°/90° 对应纬/经纱，45°/135° 对应斜纹；
- 波长 λ ∈ {4, 8}，σ = 0.56λ，γ = 0.5，核尺寸 15，**去直流 + 单位 L2 归一化** → 对亮度不敏感；
- 实部（cos）捕捉"线"的强弱/存在性，虚部（sin）捕捉**相位突变**（纬斜、稀缝、断经错位）；
- 共 16 个固定核（不学习），深度可分离卷积实现，1/4 分辨率上仅约 20 M MACs。

### 3.2 织造周期估计与尺度归一化

对灰度图做 256×256 加窗 FFT，对行/列方向功率谱取峰值并做对数谱抛物线插值：

```
period = S / f_peak  (S=256)，限制 f ∈ [S/64, S/2]，并与峰值/均值比 (confidence) 比较
```

- **数据侧**：`weave_scale_factor = target_period / period`（默认目标 8 px），把不同布种的经纬间距
  缩放到同一尺度。这一步把"纹理尺度"从模型中消除，是跨布种泛化的关键预处理。
- **模型侧**：`[log2(px/8), log2(py/8), log2(px/py), anisotropy, log1p(conf), 0]` 作为 6 维 token
  投影后加到全局分支，让网络知道"这块布多密/多斜"。
- 置信度低（纯色、强反光）时回退默认周期，不引入错误尺度。

#### 3.2.1 非正方形输入的周期估计（1440×2440）

原图 1440×2440，长宽比 1:1.69。早期实现把灰度图 `adaptive_avg_pool2d` 到 256×256 的正方形再
做 FFT，在 `1024×1728` 这种输入上等价于水平方向 14 倍抽取：周期 < 14 px 的经纬纹理在谱上
完全消失，`period_x` 退化为噪声（实测一张 6 px 周期的布面被估成 23 px），
进而 `weave_scale_normalize` 的缩放系数、全局分支的 (B,6) 织造 token 全部失真。

现在改为 **保持长宽比、只做整数倍池化**：`factor = min(H,W) // work_size`，
两个方向分别用各自的真实尺寸换算 `period = dim / k`（k 为整幅内的周期数）。
6/10 px 的经纬周期在 1024×1728、1440×2440、864×1536 上都能被精确还原（误差 < 0.1 px）。

同理，训练输入尺寸默认取 **保持长宽比** 的 `[1024, 1728]`（= 1440×2440 × 0.711），
而不是 1024×1024：正方形会把经纬方向拉伸成 1:1，让"经纬各向异性"这个最有效的
纹理线索失效，还浪费 40% 以上的像素。

### 3.3 高频归一化

`x_high = x - avgpool9(x)`，再按图归一化并裁剪到 [-6, 6]，抑制光照/色差/低频背景，
只保留织造纹理，显著降低布种间外观差异。

## 4. 全局-局部建模

- **局部**：1/8 特征 + Gabor 响应（下采样后 concat）→ 1×1 + depthwise 精炼；
- **全局**：1/32 上两级空洞卷积（rate 2、4）+ **线性注意力**：

```
q,k,v = split(conv1x1(x));  q ← ELU(q)+1, k ← ELU(k)+1
ctx = (kᵀv)/N;   out = q·ctx / (q·Σk + ε)     # O(N)，512 输入 N=256
```

- **融合**：`f = Conv1x1(local) + Up(Conv1x1(p4)) + Up(Conv1x1(global))`，再做 1×1/dw/1×1 精炼；
- **FiLM**：`f ← f·(1+γ(ḡ)) + β(ḡ)`，$\bar g$ 为全局特征的空间均值，γ、β 零初始化（训练初期不影响）。

## 5. 布面 / 布边建模（核心创新点之一）

### 5.1 布面掩码头

输入 `concat(tex(1/4), up(fused)(1/4))` → 1×1 + dw3×3（48 通道）→ 两个 1 通道输出：

- `cloth_logit`：布面 vs 背景（辊筒、导带、地面、反光金属）；
- `boundary_logit`：布边带（由布面掩码 dilate−erode 得到，带宽与分辨率相关）。

掩码弱监督来源优先级：用户真实掩码（`data.mask_dir`）> 无监督估计
（局部纹理能量 + 饱和度 + 与边缘背景色差异 → 平滑 → Otsu → 形态学 → 主导连通域）
> 全幅布面。无监督估计只在"低分区域足够大且显著低纹理"时才认定存在背景，避免错误先验。

#### 5.1.1 降分辨率估计的三个坑（`work_size="auto"`）

1. **周期必须在原始分辨率上量**。细密布经纬只有 6 px，先缩小再量会混叠（6 px 量成 28 px）。
   所以 `auto` 先在原图上找"纹理最旺"的锚点量周期，据此保证缩放后周期仍 ≥ 3 px；
   缩放后再回头量一次，量不到就 ×2 重试，实在不行退回全分辨率。
2. **窗口不能均匀撒点、也不能只看"有没有纹理"**。布幅只占画面 16% 时，
   均匀采样基本落在背景上；侥幸压到布边的窗口四条象限都有纹理（阈值能过），
   但四象限明暗差一大截，量出来的是台阶边缘的伪周期（6 px → 46 px），
   `auto` 于是把图缩到 512，纹理被平均掉，掩码糊到背景里（IoU 0.65）。
   现在的做法：先用**原图梯度幅值的块均值**定位纹理区（不能先抽样再算方差 ——
   10 px 周期可能每次采到同一相位，纹理被采样成常数），再在纹理区按窗口半径内缩取锚点，
   最后用"四象限纹理强度均匀 + 亮接近"的双重门限复核。
3. **平滑半径要跟着缩放走，几何清理要在回放分辨率上做**。
   在小图上沿用原图周期的平滑半径 (≈15 px)，回到原图就是 30 px 的边界模糊；
   而在 512 宽上做半径为 1 的开运算，回到 1440 宽就是 3 px 的边界偏差。

### 5.2 布面地理嵌入

不把绝对坐标喂给网络，而是由布面概率 `p` 推导"到布边"的软表示：

```
features = [p, AvgPool_k1(p), AvgPool_k2(p), ..., AvgPool_k5(p), 4p(1-p)]
k = 3, 7, 15, 31, 63
e = σ(1x1 + dw3x3(Concat(features)))
f ← f · (1 + e)
```

- 多尺度池化金字塔**可微**地近似距离场（布面内部 p=1，向布边递减）；
- 布边带响应 `4p(1-p)` 显式标记过渡区，重点强化布边注意力；
- 因为距离是从**当前图的布面掩码**推出来的，**布幅变化 → 布边移动 → 距离表示自动跟随**，
  模型学到的是"离布边多远/纹理是否连续"，而非"疵点在第 137 列"。

#### 5.2.1 画面边框距离先验（`border_prior`）

产线图常见两种：整幅都是布（相机只拍布面），或布幅两侧带辊筒/台面。前者时布面概率图恒为 1，
`GeographyEmbedding` 里那组多尺度池化响应全是常数、边界带 `4p(1-p)≈0`，等于**完全没有位置信息**；
而"包边不重叠 / 包边不良 / 单根包不进"这类疵点恰恰贴着布幅的左右边缘。

因此额外送入两路过归一化坐标（解析计算，零成本）：
`d_x = min(x, W-1-x) / (W/2)`、`d_y = min(y, H-1-y) / (H/2)`，与布面金字塔一起进 1×1 卷积。
这样"布边在哪"不再依赖是否拍到背景；布幅变窄时布边位置随之改变，模型也能由图上的距离梯度感知到。

### 5.3 布幅增广（`data/augment.py: fabric_width_augment`）

- 生成随机边距 `(ml, mr, mt, mb)` 的"背景画布"（深色 + 渐变 + 噪声，模拟辊筒/背景板）；
- 每条边以 `extend_prob` 概率选择"布面延伸"（复制边缘列/行，模拟布幅超出视野）；
- 图像、布面掩码、疵点掩码、标注框**同步变换**；每张图 85% 概率触发；
- 因此训练分布覆盖"布边位置任意、布幅宽窄任意、背景占比任意"，
  推理时布幅改变不再造成系统性误报。

## 6. 异常检测：学习式 + 开放集

### 6.1 学习式异常头

1/8 特征 → 1×1(32) + dw3×3 → 1 通道 logit。监督目标为
`真实框掩码 ∪ 合成疵点掩码`，损失只在**布面区域**内计算：

```
L_ano = Focal(α=0.65, γ=2) + Dice
```

α 取 0.65（偏正类）以对抗 1–2% 的正样本占比；只在布面内计算，避免把背景学成异常。

### 6.2 正常特征记忆库（开放集）

- 训练集正常图的 patch 嵌入（64d, L2）→ 容量固定 2048，k-center 贪心抽样（先随机下采样到 20k 控制复杂度）；
- 推理：`d = 1 - max_n ⟨f, m_n⟩`，归一化 `min(d/τ, 1)`（τ=0.08 为正常 patch 典型距离）;
- 与学习式分数融合：`s = (1-w)·σ(logit) + w·min(d/τ,1)`，w=0.35；
- 记忆库只依赖正常图 → **新布种可直接冷启动**；每 5 轮用最新特征重建一次，防止嵌入漂移；
- 额外的紧凑度正则 `L_compact = mean(1 - max sim)` 让正常 patch 靠近库，扩大正常/异常的分离度。

### 6.3 合成疵点（自监督）

| 生成器 | 形态 | 模拟疵点 |
|---|---|---|
| `scratch` | 折线、1–4 px、高对比 | 断经、小尾巴、划伤 |
| `stain` | 多尺度噪声阈值化 + 高斯模糊 + 颜色混合 | 油点线、棉团、污渍 |
| `cutpaste` | 同图裁块旋转后回贴 | 小布头、异物、多股线 |
| `weave_shift` | 水平带内正弦横向位移 | 纬斜、稀缝 |
| `missing_yarn` | 整条横向纱线替换 | 缺纬、断纬 |
| `foreign_fiber` | 高饱和细长曲线 | 飘絮、飞花、单根包不进 |

合成样本**只提供异常性监督**（不参与分类 CE），使"异常 vs 正常"的判断与"具体是哪一类"解耦，
这也是模型能对未见疵点保持敏感的原因。

## 7. 分类与新类发现

### 7.1 原型度量分类

- 嵌入头：dw3×3 → 1×1 → 64d → L2；
- 分类器：19 个可学习原型 `P ∈ R^{19×64}`，`logits = cos(e, P)/0.1`；
- 损失：只在**框内收缩 90%** 的像素上计算 CE（标签平滑 0.05），框外 ignore；
- 区域级 SupCon：框内掩码平均池化得到区域嵌入，同类拉近、异类推远（τ=0.1）。

选择余弦原型而不是线性 softmax 的原因：
(a) 与记忆库/聚类共享同一度量空间，新类只需加一行原型；
(b) 天然支持"开集"——最大相似度低即"未知"；
(c) 参数量极小（19×64）。

### 7.2 区域分析与区域合并

给定异常图 `s`、布面概率 `c`、类别概率图 `p`：

1. `s ← smooth(s) · 1[c > 0.5]`；
2. 阈值 `thr`（正常集校准的绝对阈值，见 §8.1）二值化 + 形态学开闭；
3. 连通域 → 面积过滤 → **主元素筛选**：保留峰值 ≥ `thr + 0.35·(max_peak − thr)` 的区域；
4. **高分核心收缩**：区域内取 `thr + 0.7·(peak − thr)` 以上的像素重算 bbox；
5. 区域类别 = 区域内 `p` 的掩码平均，取 argmax；
6. 图像级：`area_weighted`（默认）/`top1`/`max` 合并区域类别分布；
7. 图像级异常分 = 布面内 top-1% 像素均值（比 max 抗噪）。

### 7.3 新类发现

```
区域嵌入 E (N×64) ─► 余弦 k-means（k∈[2,12]，按轮廓系数选 k）
                  ─► 簇中心 C (k×64)
                  ─► 与已知原型 P 的余弦相似矩阵 S = C·Pᵀ
                  ─► 匈牙利算法求最大匹配
                  ─► 匹配相似度 < τ_novel (默认 0.55) 的簇 → 新类
```

输出：簇—已知类映射、新类原型、每个簇的样例抠图（供人工命名）。
新原型可直接 `torch.cat` 到分类器，实现**不重训主干**的增量扩容。

## 8. 训练策略

### 8.1 阈值校准（必做）

相对阈值（如"每张图取最高 k%"）会让正常图也切出区域。因此：

```
pixel_threshold = max( Quantile_{0.999}(正常图像素分数), μ + 6σ )
image_threshold = max( Quantile_{0.995}(正常图图像分数), μ + 3σ )
```

校准在**正常图**上完成，随 checkpoint 保存（`calibration` 字段），评估/推理默认使用。
这一步是像素 F1、区域召回、mAP 是否可用的前提。校准前必须先把新记忆库同步给 EMA，
否则会用到旧库、阈值系统性偏高（已在 `warmup_memory` 中处理）。

### 8.2 训练四阶段（实现上融合为一次 fit）

1. **记忆库预热**：正常图前向 → 建库（约 50 个 batch）；
2. **联合训练**：每 batch 混合正常/疵点（`normal_ratio=0.4`），损失加权：

```
L = L_ano + 0.5·L_cloth + 0.5·L_edge + 1.0·L_cls + 0.5·L_supcon + 0.1·L_compact
```

3. **记忆库周期刷新**（每 5 轮）+ 重新校准；
4. **验证与选模**：综合分
   `0.35·pixelAUROC + 0.15·PRO + 0.20·imageAUROC + 0.10·mAP50 + 0.10·mAP50_agnostic + 0.10·F1_macro`。

其他细节：
- 优化器 AdamW，头部 lr 5e-4、主干 1e-4，weight decay 0.05，warmup 3 轮 + 余弦退火；
- EMA（0.999，带 warmup：`min(d, (1+t)/(10+t))`，否则前几十步近似等于初始化权重）；
- 梯度裁剪 5.0；AMP（仅 CUDA）；
- 显存（实测，含反向）：512² 约 0.35 GB/张，1024×1728 约 1.40 GB/张，1280×2176 约 2.20 GB/张，
  故 batch 4 @1024×1728 约 5.5 GB，8 GB 卡可跑；显存不足时优先降 batch，其次降分辨率。

### 8.3 增广

随机缩放裁剪 [0.5, 1.0] → 布幅增广（85%，边距 ≤ 30%）→ hflip 0.5 / vflip 0.5 / rot90 0.25 /
小角度 ±3° → 合成疵点（50%，1–2 个）→ 颜色抖动 0.3 / gamma / 模糊 / 噪声 → 织造尺度归一化 → resize。

`data.augment.crop_mode` 有两种模式：

| 模式 | 做法 | 用途 |
|---|---|---|
| `scale`（默认） | 整图几何增广后统一 resize 到 `image_size` | 与"整图前向"的推理方式一致，保持全局布边/布幅上下文 |
| `native` | 在原始像素尺度上裁 `image_size` 大小的块（`weave_scale` 决定裁窗大小） | 疵点只有几像素时保住细节；推理需配套 `--tile` |

默认用 `scale`：1440×2440 整图缩放到 1024×1728（保留 71% 细节）时，6 px 的断经仍剩 4.3 px，
从实测看足够；只有"无论如何都检不出"的细密疵点才需要切到 `native` + 切块推理。

## 9. 复杂度与部署

- 模型：1.11 M 参数；512 输入 0.62 GMACs；所有头均为 1×1 / depthwise（早期版本使用全 3×3 时
  为 2.05 GMACs，改造后下降 3.3×，精度损失可忽略）；
- ONNX：输入 `images` + `weave_desc`，输出 `anomaly_logit / cloth_logit / boundary_logit /
  class_logits / embedding`；数值误差 < 1e-6（`--check` 校验）；计算图不含 FFT 与后处理；
- 后处理（阈值、连通域、区域合并）为纯 numpy，可等价移植到 C++/产线服务；
- 建议：TensorRT FP16 可再快 3–5×，INT8 需在正常图 + 少量疵点图上做校准。

大幅面（如 4096×1024 线扫）：`infer.tile=true`，512 瓦片 + 128 重叠，逐块前向后取 max 融合，
避免整图缩放把小疵点"抹掉"。

---

### 9.1 实时推理（40 FPS）

1440×2440 整图输入的实时性是**工程问题而不是网络问题**：网络本身在 1660 上只要 6~9 ms，
真正吃掉预算的是"把 1/8 分辨率的输出上采样回原图"和"CPU 上的形态学/连通域"。

- 输出层：分数图按 `infer.out_stride` 降到 360×610，类别概率再降一档（`probs_mul`），
  嵌入默认不返回。CPU 实测单帧前向相关开销从 906 ms 降到 58 ms（主要省掉 19 通道类别图
  与 64 通道嵌入的全分辨率上采样，约 1.2 GB 的写带宽）。
- 记忆库：查询前 2× 平均池化（`memory_stride`），乘加量 ÷4，分数图上采样回原尺寸。
- 织造周期：FFT 结果缓存 `weave_interval` 帧（默认 30），不必每帧重算。
- 后处理：形态学改成可分离平移（5.1 → 0.2 ms），连通域改成"向量化游程 + 并查集"
  （7.5 → 1.5 ms），整体区域分析 79 → 6 ms（610×360，2 核 CPU）。
- 调度：`realtime.py` 的三线程流水线把读图 / 前向 / 后处理重叠，吞吐从"三段之和"
  变成"最慢一段"。

详见 [REALTIME.md](REALTIME.md)。

## 10. 消融实验计划（建议按此顺序验证）

| 编号 | 变量 | 预期结论 |
|---|---|---|
| A0 | 完整模型 | 基线 |
| A1 | 去 Gabor（纹理分支） | 小疵点召回、跨布种 AUROC 下降 |
| A2 | 去织造尺度归一化 | 换布种时明显退化（尺度失配） |
| A3 | 去全局分支 | 整幅性缺陷（纬斜）与布边误报增加 |
| A4 | 去布面掩码 / 地理嵌入 | 背景误报与布边误报显著增加；换幅宽后更明显 |
| A5 | 去布幅增广 | 布幅变化时边缘区域 F1 下降 |
| A6 | 去记忆库（仅学习式） | 新布种冷启动/未知疵点 AUROC 下降 |
| A7 | 去合成异常 | 稀有类与弱对比疵点召回下降 |
| A8 | 去 SupCon | 相似类混淆（如断经 vs 多股线）F1 下降 |
| A9 | 阈值：相对 vs 校准 | 像素 F1、区域数量、误报率差异显著 |

度量口径建议：按**布种/幅宽**分组统计 AUROC 与 F1，观察跨域 gap；单独报告 `map50_agnostic`
与 `map50` 以区分定位与分类瓶颈。

## 11. 已知局限与后续方向

1. **分类精度依赖框标注质量**：框内像素做弱监督，框过大/过松会稀释监督；可引入
   "框内 CAM/异常峰值" 的软权重。
2. **1/8 异常图的分辨率上限**：极细（< 2 px）疵点建议提高输入分辨率或用 1/4 异常头。
3. **织造尺度归一化在大幅面上是全局统计**：一幅图内若并存两种密度（拼接布），会失配；
   可改为分块估计。
4. **记忆库容量固定**：布种特别多时可做分层记忆库（按布种/周期聚类分库）。
5. **新类发现依赖聚类质量**：轮廓系数在长尾分布下偏保守，可用"已知类验证集"标定的
   相似度阈值替代。
6. **时序信息未用**：线扫产线天然有帧间连续性，接入简单的时序平滑/跟踪可进一步降误报。
